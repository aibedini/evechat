# صفحه‌های دمو (فقط لوکال)

پکیج `web/demo` پنج صفحه دارد که سرور با کلید پروژه و آدرس عمومی همان نصب
پرش می‌کند. همه‌ی مسیرهای `/demo*` فقط از loopback سرو می‌شوند؛ هر درخواست
دیگری **404** می‌گیرد (نه 403، که وجود مسیر را تأیید می‌کند). هیچ‌کدام از این
صفحه‌ها در production به‌طور پیش‌فرض فعال نیست.

| مسیر | کار |
|---|---|
| `GET /demo` | فروشگاه ساختگی + نوار کنترل + ۷ سناریوی شبیه‌سازی |
| `GET /demo/test` | صفحه‌ی تست ساده (دکمه‌های ec(...)) |
| `GET /demo/split` | اندازه‌گیری تأخیر واقعی رفت‌وبرگشت بر حسب ms |
| `GET /demo/devices` | ۸ پیش‌تنظیم دستگاه با iframe زنده |
| `GET /demo/events` | کنسول رویدادهای پروتکل |
| `GET /demo/demo.css` | `demo.js` | دارایی‌های مشترک |

## نوار کنترل

هر گزینه با پارامتر URL بازسازی می‌شود تا وضعیت قابل اشتراک باشد:

```
?position=bottom-right|bottom-left
?theme=dark|light|auto
?locale=en|fa
?font=none|inherit|vazirmatn
?offline=1        fetch و WebSocket را عمداً شکست می‌دهد
?ws=0             WebSocket را حذف می‌کند تا زنجیره‌ی SSE → long-poll دیده شود
?eve=1            هویت و متادیتای EVE را به ویجیتور می‌دهد
```

در `?offline=1` پیام‌ها در outbox می‌مانند و پس از بازگشت شبکه ارسال می‌شوند؛
در `?ws=0` نشانگر اتصال باید به `degraded` برود و پیام‌ها از مسیر جایگزین
عبور کنند.

## ۷ سناریوی شبیه‌سازی

1. باز کردن پنل (`ec('open')`)
2. بستن پنل
3. ارسال پیام و اندازه‌گیری تأخیر
4. شناسایی کاربر (`ec('identify')`)
5. ست کردن متغیر (`ec('setVariable', plan, pro)`)
6. قطعی اینترنت (reload با `offline=1`)
7. مسدودسازی WebSocket (reload با `ws=0`)

## تداخل CSS عمدی

دکمه‌ی «تداخل CSS» یک استایل خصمانه را فعال می‌کند که روی `button`، `*` و حتی
کلاس‌های `.ec-*` اثر می‌گذارد. چون ویجت داخل Shadow DOM است، ظاهر و کارکردش
نباید تغییر کند؛ تست `demo.spec.ts` همین را assert می‌کند.

## بودجه

کل دارایی‌های دمو زیر **۲۴KB** است (سقف پلن: ۳۰۰KB) و
`TestDemoBundleStaysUnder300KB` در `web/demo/demo_test.go` آن را تضمین می‌کند.

## امنیت

- گیت loopback با `middleware.ClientIPWithProxies`؛ هدر `X-Forwarded-For`
  فقط وقتی `trust_proxy=true` باشد و اتصال از یکی از `server.trusted_proxies`
  آمده باشد اثر دارد.
- کلید پروژه با escape مخصوص رشته‌ی JS تزریق می‌شود (`< > & " \`).
- صفحه‌ها `Cache-Control: no-store` دارند تا کلید در کش مشترک نماند.
