# راه‌اندازی ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید، `/newbot` را بزنید و توکن را بگیرید.
2. در `.env` (یا تنظیمات یکپارچه‌سازی پنل) وارد کنید:

```
EVECHAT_TELEGRAM__BOT_TOKEN=123456:ABC...
EVECHAT_TELEGRAM__ENABLED=true
EVECHAT_TELEGRAM__SECRET=<یک رشته تصادفی>
EVECHAT_TELEGRAM__WEBHOOK_URL=https://chat.example.com/api/v1/integrations/telegram/webhook
```

3. سرویس را ری‌استارت کنید. اگر webhook خودکار ثبت نشد:
   `POST /api/v1/integrations/telegram/set-webhook` (با توکن پنل) یا مستقیم از پنل: تنظیمات ← یکپارچه‌سازی‌ها ← «ثبت وب‌هوک».
4. شناسه عددی تلگرام خود را در **تنظیمات ← تیم** ثبت کنید و «ارسال تست» را بزنید.
5. یک قانون مسیریابی با `route_to.telegram_id` بسازید (یا `default_telegram_id` پروژه را تنظیم کنید).

## چه اتفاقی می‌افتد

- گفتگوی جدید به شکل یک کارت با دکمه‌های «مشاهده در پنل»، «بستن گفتگو» و «ارجاع به پشتیبان» ارسال می‌شود.
- پاسخ با Reply داخل تلگرام به همان گفتگو برمی‌گردد و به‌عنوان پیام کارشناس ثبت می‌شود.
- پیام‌های بعدی کاربر هم در همان چت ارسال می‌شوند (هر ۷۲ ساعت نگاشت پیام نگه داشته می‌شود).
- محدودیت ارسال: ۲۵ پیام در ثانیه؛ در صورت دریافت ۴۲۹، مقدار `retry_after` رعایت می‌شود.

## عیب‌یابی

| مشکل | بررسی |
|---|---|
| ربات پاسخ نمی‌دهد | `getWebhookInfo` در API تلگرام؛ آدرس عمومی باید HTTPS معتبر باشد |
| «امضای تلگرام نامعتبر» | `EVECHAT_TELEGRAM__SECRET` با آنچه ثبت شده یکی نیست |
| پیام‌ها به گفتگو نمی‌رسند | باید با Reply روی پیام ربات پاسخ دهید، نه پیام جدید |
| دکمه‌ها کار نمی‌کنند | نسخه ربات را ری‌استارت کنید تا کیبورد تازه ساخته شود |
